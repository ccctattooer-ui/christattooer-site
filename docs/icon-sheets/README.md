# Icon sheets

The two original sheets Chris generated. They live here rather than in `assets/` so they are
kept in the repo but never shipped to visitors — together they are 4.6 MB.

`tools/split_icons.py` cuts them into the individual transparent PNGs in `assets/icons/`.
Cell boxes and caption clips in that script were measured off these exact files, so if a sheet
is ever regenerated the numbers will need checking again.

- `Icons_1_FirstPicks.png` — the working set. 10 large icons, 36 small ones. Bold and high
  contrast, which is why it survives being shrunk to 56px and 16px.
- `Icons_2_supplementary.png` — the same subjects in a holographic palette. Softer, so it goes
  muddy at small sizes; kept as sticker art, where it is shown big.
